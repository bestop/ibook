# 童学冒险岛 · 微信小程序端

与网页版（https://www.hikid.org）配套的原生微信小程序，**教材与闯关内容全部从数据域名 https://lx.hikid.vip 实时获取**（与网页版同一服务、同一内容），本地只保存学习进度（金币、星级、错题本、成就、礼物屋）。

## 功能

- 🏝️ 首页科目岛：年级 / 上下册 / 出版社（全部 / 人教版 / 沪教版）三维筛选，与网页版选择器同语义
- 🏰 闯关地图：过一关解锁下一关，星级展示，每日挑战（已解锁单元随机 10 题）
- ⚔️ 答题闯关：3 命 + 每题 40 秒倒计时 + 连击金币（连击 3 次以上每题 +5）+ 即时解析
- 🌟 星级结算：全对 3 星 / 错 1 题 2 星 / 错 2 题 1 星；通关奖励 20/50/100 金币；生命用完本局金币减半
- 📕 错题本：答错自动收录（本地快照，复习免联网），复习答对即消灭，答对 5 题完成每日任务
- 🎁 礼物屋：金币兑换亲子奖励（默认 6 项 + 家长自定义），兑换券家长标记「已兑现」
- 🏆 我的：每日签到（+10 金币 / 连续天数）、每日 20 分钟任务（自动计时）、学习统计、成就墙
- ✅ 每日任务：闯 1 关 +20 / 玩满 20 分钟 +30 / 复习答对 5 题 +10

## 数据同步机制

| 接口 | 说明 | 缓存策略 |
|------|------|----------|
| `GET https://lx.hikid.vip/api/mp/manifest` | 44 个科目岛元信息 + 关卡清单 + 全库版本号 | 启动时拉取，离线兜底读缓存 |
| `GET https://lx.hikid.vip/api/mp/bank?subject=<id>` | 单科目全部关卡与题目（约 15~70KB） | 按 `version`（内容哈希）增量缓存，命中免下载 |

网页端题库更新并重新部署后 `version` 自动变化，小程序下次启动即增量同步，无需发版。

> **域名说明**：请求域名依次为 `https://lx.hikid.vip` → `https://www.hikid.org`（主域不可用时自动回退，两者指向同一服务）。`request 合法域名` 中**必须添加主域 lx.hikid.vip**，建议同时添加 www.hikid.org 作备用；只添加主域时回退请求会被微信拦截（不影响正常使用）。

## 使用步骤（家长）

1. 下载安装「微信开发者工具」（https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html）
2. 打开开发者工具 → 导入项目 → 选择本 `miniprogram` 文件夹
3. AppID：填入自己的小程序 AppID（没有可先用「测试号」，即 `project.config.json` 中的 `touristappid`）
4. 开发调试阶段：右上角「详情 → 本地设置」勾选「不校验合法域名…」即可直接联网调试
5. **正式发布前**：登录微信公众平台（mp.weixin.qq.com）→ 开发管理 → 开发设置 → 服务器域名 → 在 `request 合法域名` 中添加 `https://lx.hikid.vip`（建议同时添加备用 `https://www.hikid.org`）
6. 上传代码 → 提交审核 → 审核通过后发布

## 目录结构

```
miniprogram/
├── app.js / app.json / app.wxss     # 全局：启动拉取 manifest、页面注册、暖色风格
├── project.config.json              # 开发者工具项目配置（AppID 在此修改）
├── utils/
│   ├── api.js                       # 数据同步层（manifest / bank 拉取与版本化缓存）
│   ├── store.js                     # 进度存储 + 游戏机制（与网页版 game.ts 同构）
│   └── quiz.js                      # 组卷（洗牌 / 选项打乱 / 每日挑战 / 错题复习）
├── components/mp-tabbar/            # 自定义底部导航
└── pages/
    ├── home/                        # 首页：三维选择器 + 科目岛
    ├── map/                         # 闯关地图：关卡列表 + 每日挑战
    ├── quiz/                        # 答题：3 命 / 40s / 连击 / 解析
    ├── result/                      # 结算：星级 / 金币明细
    ├── wrongbook/                   # 错题本：快照复习，答对消灭
    ├── rewards/                     # 礼物屋：兑换 / 券包 / 自定义奖励
    └── profile/                     # 我的：签到 / 任务 / 统计 / 成就墙 / 重置
```

## 与网页版的关系

- ✅ 同步：教材题库（38 科目岛 / 311 关 / 3110 题，含语文下册）、关卡解锁规则、金币与星级规则、奖励与任务数值
- 🔒 各自独立：学习进度分别保存在浏览器 localStorage 与微信本地存储中（后续如需云端账号互通，可在此数据层上扩展）
